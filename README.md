# houss.am

My personal website: who I am, what I work on, and where I worked before. In English at
[houss.am](https://houss.am) and in French at [houss.am/fr](https://houss.am/fr/).

Plain HTML and CSS, hosted on GitHub Pages.

## Layout

- `index.html`: the English page
- `fr/index.html`: the French page
- `CNAME`: the custom domain for GitHub Pages
- `sitemap.xml`, `robots.txt`, `site.webmanifest`, favicons
